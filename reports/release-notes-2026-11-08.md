## What's new

08 Nov 2026

### Improvements
- If you run the board behind a reverse proxy, the limits on logins, sign-ups and emails now work properly for visitors on IPv6. Before, one visitor could get around them by switching between the many addresses they own; now all of those addresses count as one visitor. The log still records the exact address.
- Addresses that aren't real addresses are now ignored instead of being counted.
